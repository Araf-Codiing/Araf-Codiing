JavaScript - Complete A-Z

1. What is JavaScript?

JavaScript = Programming Language for Web
- Created by Brendan Eich in 1995 in 10 days
- Makes website interactive and dynamic
- Runs in browser (Client-side) and server (Node.js)
- Latest version ECMAScript 2024 (ES15)
- Not related to Java - different language

2. Features of JavaScript - 10 Points

  • Dynamic and interactive - responds to user actions
  • Lightweight, interpreted language - no compilation needed
  • Object-Oriented and Event-driven programming
  • Works with HTML and CSS - controls DOM
  • Cross-browser compatible - all browsers support
  • Handles form validation, animation, API calls
  • Supports ES6 modern syntax - let, const, arrow function
  • Asynchronous programming - Promise, async/await
  • Large ecosystem - React, Vue, Node.js libraries
  • Both front-end and back-end (MERN stack)

3. How to Add JavaScript - 3 Ways

1. Internal JS: <script> alert("Hello"); </script> - Inside HTML head or body 2. External JS: <script src="app.js"></script> - Separate .js file, BEST 3. Inline JS: <button onclick="alert('Hi')"> - Inside tag attribute
