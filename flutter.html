Flutter - Complete A-Z

1. What is Flutter?

Flutter = UI Toolkit for Building Natively Compiled Apps
- Created by Google in 2017
- Language: Dart (also by Google)
- One codebase for Android, iOS, Web, Desktop
- Uses Widgets - Everything is a Widget
- Latest version Flutter 3.22 with Impeller engine
- Fast, beautiful, open-source

2. Features of Flutter - 10 Points

  • Single codebase for 6 platforms - Android, iOS, Web, Windows, macOS, Linux
  • Hot Reload - See changes instantly in 1 second
  • Everything is Widget - Text, Button, Padding all widgets
  • Fast performance - Compiles to native ARM code, 60/120 FPS
  • Beautiful UI - Material Design and Cupertino (iOS) widgets built-in
  • Open Source and free - Large community support
  • Dart language - Easy to learn, similar to JavaScript/Java
  • Rich widget library - 1000+ ready widgets
  • State Management - Provider, Bloc, Riverpod, GetX
  • Backed by Google - Used by Google Pay, eBay, Alibaba

3. Types of Widgets - 3 Main Types

1. StatelessWidget: No state change - static screen like Text, Icon Example: class MyApp extends StatelessWidget 2. StatefulWidget: State can change - dynamic screen like Checkbox, Form Example: class MyApp extends StatefulWidget + createState() 3. InheritedWidget: Passes data down the tree - like Theme, Provider Example: InheritedWidget for sharing data

4. Flutter Architecture - Core Concept

Everything is a Widget Tree: MaterialApp └─ Scaffold ├─ AppBar ├─ Body (Column / Row / Container) │ ├─ Text │ ├─ Image │ └─ Button └─ FloatingActionButton Formula: UI = f(State) - UI changes when State changes
