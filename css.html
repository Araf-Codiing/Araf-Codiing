CSS - Complete A-Z

1. What is CSS?

CSS = Cascading Style Sheets
- Created by Hakon Wium Lie in 1996
- Used to style HTML document
- Controls color, layout, font, spacing, animation
- Latest version CSS3 (Modular)

2. Features of CSS - 10 Points

  • Styles HTML elements - makes website beautiful
  • One CSS file can control 1000 HTML pages
  • Responsive design - mobile, tablet, desktop friendly
  • Fast loading - less code, external file cached
  • Supports animation, transition, hover effects
  • SEO friendly and browser compatible
  • Reusable and maintainable code
  • Multiple device compatibility
  • Supports Flexbox and Grid layout
  • Time saving - separation of content and design

3. Types of CSS - 3 Types

1. Inline CSS: <p style="color:red;"> - Direct in tag, highest priority
2. Internal CSS: <style> p{color:red;} </style> - Inside head tag
3. External CSS: <link rel="stylesheet" href="style.css"> - Separate file, BEST and most used

4. Box Model - Core Concept of CSS

MARGIN - Outside space
BORDER - Border line
PADDING - Inside space
CONTENT - Actual text/image

Formula: Total Width = Content + Padding + Border + Margin
Feature: box-sizing: border-box makes calculation accurate
